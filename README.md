# Pharma-Connect

Pharma-Connect is a web application designed to improve access to medicines by connecting users with pharmacies. It allows users to search for medicines, create accounts, and interact with a backend system that manages data efficiently.

---

## Features

- User Registration & Login (Authentication)
- Medicine Search Functionality
- Backend API using Node.js and Express
- Secure authentication using JWT

---

## Technologies Used

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

- Node.js installed → https://nodejs.org/
- A code editor like VS Code (recommended)

---

## FULL INSTALLATION & SETUP GUIDE

Follow these steps carefully to run the project successfully:

### 1. Clone the Repository

Open your terminal and run:

git clone https://github.com/yohan2330/Pharma-Connect.git

Then move into the project folder:

cd Pharma-Connect

---

### 2. Setup the Backend

Navigate to the backend folder:

cd Backend

Install all required dependencies:

npm install

---

### 3. Create Environment Variables

Inside the Backend folder, create a file named:

.env

Add the following inside:

PORT=5000

---

### 4. Start the Backend Server

Run the following command:

npm start

OR if you use nodemon:

npm run dev

If everything works, you should see:

Server running on port 5000  

---

### 5. Setup the Frontend

Open a new terminal and go to the frontend folder:

cd Frontend

If the frontend is built with HTML/CSS/JavaScript:

- Open index.html directly in your browser  

OR  

- Use Live Server in VS Code for better experience  

---

## HOW TO USE THE APPLICATION

1. Open the frontend in your browser
